# Network Lab Experiment

## Aim

To implement TCP client-server communication using socket programming in C.

## Commands Used

```bash
gcc server.c -o server
gcc client.c -o client
./server
./client
```

## Procedure

The server is started in one terminal and the client is started in another. The client sends data to the server through a TCP socket, and the server processes the data and returns the result.

## Output

The client-server programs were executed successfully and the required results were obtained.

## Conclusion

TCP client-server communication was successfully implemented using C socket programming.
